## App Runtime Subprocessor

| Provider | Service | Purpose | Data involved | Provider information |
| --- | --- | --- | --- | --- |
| Atlassian Pty Ltd and applicable Atlassian affiliates | Jira Cloud, Atlassian Forge, Forge hosted storage, authentication, licensing, and platform operations | Host and operate the App, provide Jira data, authenticate users, store planning data, and manage Marketplace licensing | Jira issue data, Atlassian account information, App configuration, and planning records as described in the Privacy Policy | [Atlassian Trust Center](https://www.atlassian.com/trust) |

Product Radar does not currently use another external subprocessor to receive
Jira or planning data during the App's standard runtime operation.

## Documentation Hosting

GitHub Pages hosts this public documentation and legal site. GitHub may process
visitor request information when someone opens these pages. The App does not
send Jira data or stored planning records to GitHub Pages.

| Provider | Service | Purpose | Data involved | Provider information |
| --- | --- | --- | --- | --- |
| GitHub, Inc. | GitHub Pages | Host public documentation, support, privacy, and security pages | Website request and usage information processed independently by GitHub; no Jira data is sent by the App | [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) |
